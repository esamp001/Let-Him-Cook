# Follow My Coding

Apply the current coding standards in Let-Him-Cook before implementing, fixing, or refactoring code in this repository.

1. Locate the repository root and open its `AGENTS.md`. Read the entire `## Coding Standards` section, including every nested heading, bullet, and code example, through the next level-two heading or the end of the file. Read it again for each new code-change task because the standards may have changed. Do not rely on a remembered summary or this skill as a substitute for the file.
2. Before editing, identify which standards apply to the files and behavior being changed. Follow all applicable items while preserving the project's existing architecture and any additional instructions in relevant `AGENTS.md` files.
3. After editing, review the changes against the complete Coding Standards section and run the relevant project checks. Correct any violations introduced by the change before reporting completion.
4. Do not silently skip a standard. If a standard cannot be followed, state the specific conflict or limitation. Follow higher-priority instructions and explicit user directions when they take precedence.

Keep `AGENTS.md` as the source of truth. Do not copy its coding rules into this skill.
